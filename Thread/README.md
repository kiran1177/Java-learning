# Java Multithreading

This folder contains Java programs demonstrating multithreading concepts through practical examples.

## Topics Covered

- Creating Threads using `Thread` and `Runnable`
- Thread Life Cycle
- Thread Priority
- Thread Methods: `sleep()`, `join()`, `yield()`, and `isAlive()`
- Synchronization using the `synchronized` keyword
- Thread Communication using `wait()`, `notify()`

## Purpose

The programs in this folder are intended to strengthen understanding of Java multithreading, thread management, synchronization, and communication between threads.
