# Recursion in Java

This folder contains Java programs to understand recursion and practise problem-solving step by step.

## Topics Covered

- Basic Recursion
- Printing Numbers Using Recursion
- Factorial and Fibonacci Series
- Palindrome Checking
- Reversing Numbers
- Reversing Odd Numbers
- Subsequences of an Array

## Learning Objectives

- Understand how recursive methods work.
- Learn base conditions and recursive calls.
- Practise breaking problems into smaller subproblems.
- Understand backtracking through subsequence generation.
